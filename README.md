#  MedHelper

**MedHelper** — это веб-приложение для онлайн-бронирования времени для сдачи анализов в клинике.  
В проекте реализованы функции умных напоминаний, загрузки и анализа медицинских отчётов, встроенный AI-ассистент и советы по здоровью.

Бэкенд разработан на **Django** и **Django REST Framework**,  
фронтенд — на **React**,  
база данных — **PostgreSQL**.


##  Технологии

- **Backend:** Django, Django REST Framework, PostgreSQL, Mailgun, JWT
- **Frontend:** React, TypeScript, React Query
- **AI:** GPT-3.5 Turbo via OpenAI API
- **DevOps:** Render, GitHub, Docker (в планах)
- **API:** RESTful API
